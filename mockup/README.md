# Макет веб-приложения Evercoin

Кликабельный прототип интерфейса приложения личных финансов для согласования перед разработкой. Это не само приложение: данные вымышлены, сервера нет, изменения живут до перезагрузки страницы.

Вид взят из AI Capper ([ai_agent_capper/mockup](https://github.com/rvburov/ai_agent_capper/tree/master/mockup)): те же цвета и токены (`--bg`, `--surface`, `--accent` и остальные — значения без изменений), шрифты Geologica, Golos Text и JetBrains Mono, оболочка (боковое меню на компьютере, нижние вкладки с кнопкой «+» на телефоне), карточки, кнопки, сегменты, выпадающий список, окна-шторки, графики, светлая и темная темы.

## Как открыть

- **Онлайн:** https://claude.ai/artifact/MgBVs7JSsoHvSNnCKEb5Xo (открывается под аккаунтом владельца). Работает на телефоне и на компьютере.
- **Локально:** запустите статический сервер из корня репозитория и откройте страницу:

  ```bash
  python3 -m http.server 8080 --bind 127.0.0.1 --directory mockup
  # затем http://localhost:8080 (с сервера — через ssh -L 8080:127.0.0.1:8080)
  ```

  Файл `index.html` написан как содержимое страницы (без `<!doctype>` и `<head>`, их добавляет публикация), как в макете AI Capper. В браузере открывается и так.

## Экраны

| Экран | Адрес | Что показывает |
|---|---|---|
| Вход | `#login` | Вход, регистрация, сброс пароля по ссылке на почту. Подойдет любой пароль, кроме `wrong` |
| Главная | `#dashboard` | Всего на счетах (копейки мельче рублей, «глаз» скрывает суммы), график за 30 дней, 3 месяца или год; месяц: доходы, расходы, сколько осталось, доля потраченного, средний расход в день и прогноз до конца месяца; расходы по категориям; последние операции; плитки счетов |
| Операции | `#operations` | Месяц стрелками, тип (все, расходы, доходы, переводы), поиск, счет; итоги периода; список по дням с суммой трат за день. Нажатие — окно операции: изменить, повторить, удалить с подтверждением |
| Новая операция | `#new`, кнопка «+» и «Операция» | Расход, доход или перевод; сумма крупно, категории плиткой, счет, название, дата, комментарий. Перевод между валютами пересчитывает сумму по курсу, ее можно поправить |
| Счета | `#wallets` | Всего на счетах, долг по картам, счета вне общего баланса; карточки счетов с остатком, пересчетом в основную валюту и движением за месяц |
| Счет | `#wallet-<id>`, например `#wallet-card`, `#wallet-usd` | Остаток и график за 30 дней, доходы и расходы за месяц, основной счет, «учитывать в общем балансе», изменение, удаление (только без операций), операции по счету |
| Категории | `#categories` | Расходы и доходы: доля и сумма за месяц, правка названия, значка и цвета, объединение с другой категорией, отключенные категории |
| Аналитика | `#analytics` | Месяц, 3 месяца или год: доходы, расходы, сколько отложено, расход в день со сравнением с прошлым периодом; доходы и расходы по месяцам за год; структура расходов; крупные расходы |
| Профиль | `#profile` | Основная валюта (общий баланс и аналитика пересчитываются), тема, скрытие сумм, пароль, выход на других устройствах, выгрузка CSV, удаление аккаунта с подтверждением |

Прямая ссылка на экран (например, `index.html#analytics`) открывает его без входа — так удобнее согласовывать. Адрес настроек — `#profile`: `#settings` в артефактах занят.

## Решения, которые нужно согласовать

1. **Минимализм.** На каждом экране одна главная сумма. Цвет категории — только метка (значок, полоса доли, график). Красный — только для проблем: долг по карте, перерасход. Расходы пишутся обычным цветом со знаком «−», доходы — зеленым со знаком «+», переводы — серым.
2. **Копейки мельче рублей.** В крупных суммах копейки показаны меньшим и более светлым шрифтом, в списках круглые суммы — без «,00».
3. **Общий баланс** считается в основной валюте по курсу и не включает счета с выключенным «Учитывать в общем балансе» (в примере — брокерский счет).
4. **Счет с операциями не удаляется** (как в backend Evercoin): сначала удалить или перенести операции. Основной счет один, он подставляется в новые операции.
5. **Категорию с операциями не удаляем, а объединяем** с другой; стандартные категории можно отключить — история и отчеты не теряются.
6. **Телефон:** нижние вкладки «Главная, Операции, +, Аналитика, Еще»; «Счета», «Категории» и «Профиль» — в «Еще». Окна выезжают шторкой снизу, зоны нажатия не меньше 40 px.

## Как устроен

```
mockup/
├── index.html           токены AI Capper, стили, подключение скриптов
├── js/ui.js             UI-кит: элементы, иконки, деньги и даты, компоненты, графики
├── js/data.js           демо-данные: 6 счетов, 13 категорий, ~500 операций за год (случайность с постоянным зерном)
├── js/parts.js          общие части: строка операции, список по дням, окна операции, счета, категории
├── js/app.js            оболочка, роутер по #адресу, тема, вход
└── js/screens/*.js      экраны
```

Остатки счетов не хранятся отдельно: они считаются из начальных остатков и операций. Поэтому добавленная в макете операция сразу меняет баланс, графики, итоги месяца и аналитику.
