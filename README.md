# Evercoin

Компактный мобильный веб-макет личных финансов по 24 экранам пользователя.
Предназначен для согласования в браузере телефона iOS или Android.
Стек React + TypeScript + Vite взят из
[AI Capper](https://github.com/rvburov/ai_agent_capper), правила разработки
адаптированы из его `CLAUDE.md` в `AGENTS.md`.

## Запуск

Требуется Node.js 22.12+ или 24 LTS.

```bash
npm ci
npm run dev
```

Сервер запускается на порту 3000. Проверка TypeScript и сборка выполняются
одной командой.

```bash
npm run build
```

Автономный макет — `dist/index.html`. После сборки его можно открыть
в браузере. CSS и JavaScript встроены в HTML через `vite-plugin-singlefile`.
Исходники доступны в `index.html`, `src/*.tsx`, `src/*.css` и `src/data.ts`.


Готовый HTML для просмотра сохранен в `mockup/index.html`. Это копия
согласуемой сборки из `dist/index.html`. После изменения исходников выполните
`npm run build` и обновите эту копию.

## Сценарии

- Главный экран с балансом, доходами, счетами и категориями расходов.
- Свайп между страницами доходов, счетов и расходов, редактирование плиток.
- Перенос дохода на счет и счета на расход открывает создание операции.
- Ввод суммы калькулятором, дата, заметка, метки и параметры повторения.
- Лента операций, фильтры, линейный и круговой графики, выбор периода.
- Редактирование счета или категории, бюджет, цель и выбор иконки.
- Настройки, демонстрационный профиль и финансовый помощник.

Демонстрационный период — ноябрь 2026 года. Суммы хранятся целыми копейками,
операции связывают источник и назначение. Изменения сохраняются в localStorage
этого браузера. Параметры повторения сохраняются в операции.

Помощник демонстрирует разбор фраз и ответы по данным макета. Перед записью
операции открывается черновик для проверки. Реальный ИИ и серверное хранение
подключаются после согласования дизайна. Голосовой ввод использует
распознавание браузера и зависит от его поддержки, разрешения на микрофон
и HTTPS или localhost. Для просмотра сценария доступен демопример.

## Основные файлы

- `src/App.tsx` — навигация и состояние.
- `src/Home.tsx` — главный экран и страницы плиток.
- `src/Feed.tsx` — лента, фильтры и отчеты.
- `src/ItemEditor.tsx` — параметры элементов и иконки.
- `src/OperationComposer.tsx`, `src/Calendar.tsx` — создание операции и даты.
- `src/Settings.tsx`, `src/Profile.tsx` — настройки и профиль.
- `src/Assistant.tsx` — финансовый помощник.
- `src/style.css` и CSS рядом с компонентами — оформление.
- `src/data.ts`, `src/useFinanceDrag.ts` — данные, вычисления и перетаскивание.
